1. Python script that utilizes ML methods SVM, Random Forest and XGBoost with GridSearchCV ML tuning method.
2. Has a framework and is a complete script from the initial input data reading, cleaning, outlier detection/removal, z-score standardization, plotting, feature importance scoring, metrics, all the way to ROC/AUC curve generation and further on mapping predictions. 
3. All required libraries included in the script, might need installations depending on users local system.  
All in all a complete package, suited for a Masters thesis for similar kind of analysis.
